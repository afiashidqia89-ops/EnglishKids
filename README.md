# Hafalan Juz Amma
Upload semua isi folder ke repo GitHub (branch `main`) → Actions → Build APK → unduh `hafalan-juz-amma-apk`.
Saat build, `tools/fetch_quran.py` mengunduh teks (alquran.cloud) dan audio per ayat (everyayah.com, Mishary Alafasy)
sehingga APK bisa dipakai offline. Teks tidak diketik manual. Mohon ditashih oleh ustaz/ustazah sebelum dipakai anak.
